A high-performance, responsive 3D interactive portfolio website built for **Muhammad Sikandar Mustafa** (Software Engineer & Python Backend Developer), showcasing real-world microservices, AI agents, HOS-compliant route planning APIs, and multi-tenant platforms.

---

## ✨ Features

- **3D Interactive Hero**: Dynamic Three.js WebGL displacement sphere with GLSL custom shader animated in a warm orange & amber theme (`#FF9E20`).
- **Featured Projects**:
  - **Proplytics** ([proplytics.ae](https://proplytics.ae/)): Multi-tenant real estate CRM microservices architecture with FastAPI, Celery, multi-modal WhatsApp LLM agent, and Bayut & PropertyFinder API integrations.
  - **Scaffold**: AI Agent platform for creatives (FastAPI, Supabase, Celery, Redis).
  - **TruckRoute Planner**: HOS-compliant route planning & ELD log generation API (Django REST Framework, Celery).
  - **DMT Backend**: Device management system with GCP Pub/Sub & S3 storage.
- **Custom Design System**: Vanilla CSS tokens with PostCSS, smooth framer-motion page transitions, dark/light theme toggle, and responsive mobile navigation.
- **Developer Stack (`/uses`)**: Details Python backend technologies, frameworks, databases, and DevOps tools.
- **Contact Form (`/contact`)**: Built-in validation with optional Cloudflare & AWS SES integration.

---

## 🛠️ Tech Stack

- **Framework**: [Remix](https://remix.run/) + [Vite](https://vitejs.dev/)
- **Frontend**: [React 18](https://react.dev/), [Framer Motion](https://www.framer.com/motion/), [Three.js](https://threejs.org/)
- **Styling**: Vanilla CSS, PostCSS, Custom OKLCH / Hex Color Tokens (`#FF9E20`)
- **Backend Stack**: Python (FastAPI, Django REST Framework), PostgreSQL, Redis, Celery, Docker, GCP

## 🚀 Getting Started

### Prerequisites

- **Node.js**: `>=19.9.0`
- **npm**: `>=9.0.0`

### Installation

```bash
# Clone the repository
git clone https://github.com/sikandar-rajpoot/portfolio.git
cd portfolio

# Install dependencies
npm install
```

### Development Server

Start the Vite development server on `http://localhost:7777`:

```bash
npm run dev
```

### Production Build

Build the client and server assets for deployment:

```bash
npm run build
```

Preview the build locally via Cloudflare Wrangler:

```bash
npm run start
```
